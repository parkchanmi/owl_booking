# 마이페이지 실제 데이터 연동

2026-11-01 기준. 공지사항·이벤트의 콘텐츠와 프로모션은 요청대로 기존 목업을 유지했다.

## 연결한 항목

| 화면 | 데이터와 처리 |
|---|---|
| 센터·프로필 | 실제 센터 목록·주소·전화, 로그인 회원 이름·아이디·연락처·로그인 방식 |
| 통계 | 선택 센터의 이번 달 예약 건수, 기록된 출석/결석 기준 출석률, 미래 수업의 대기 건수 |
| 달력·다가오는 일정 | 실제 예약·출석·결석·대기 일자, 현재 날짜, 예약된 미래 수업 |
| 예약 내역 | 예약·출석·결석·대기 조회, 날짜/상태 필터, 본인 예약·대기 취소, 성공 후 전체 데이터 재조회 |
| 이용권 | 실제 명칭·기간·잔여 횟수·등록 결제일·등록 금액, 만료/소진 내역, 예약/출석 기준 차감 이력 |
| 일시정지 | 본인 이용권의 기록 조회·기간 등록. 기존 중복 기간/가용 일수 검증 재사용. 오늘 이전 시작일은 거절 |
| 환불 | 본인 이용권의 실제 예상 환불액과 센터 기준 조회. 회원 신청/결제 취소는 실행하지 않음 |
| 설정 | 회원 정보 조회와 이메일·전화번호 저장 |

회원용 API는 세션에서 본인을 결정하고, 이용권·예약·대기 변경 전 소유자를 확인한다. 예약 취소는 센터의 취소 제한 시간을 서버에서도 검사한다. API 실패는 빈 결과와 구분하여 재조회할 수 있다.

## 추가 구현이 필요한 항목

| 항목 | 필요한 저장 구조·API/정책 | 현재 처리 |
|---|---|---|
| 공지사항·이벤트·프로모션 | 센터별 게시물 테이블, 게시 기간/노출/상세 콘텐츠 관리 API. 실제 이벤트 참여가 필요하면 참여 테이블과 정원/중복 신청 정책 | 기존 목업 유지 |
| 알림함·읽음/삭제 | 회원별 알림 및 읽음 상태 테이블, 조회/읽음/삭제 API | 샘플 예약 알림 제거, 빈 알림함 |
| 알림 수신 설정·마케팅 동의 | 회원별 수신 설정/동의 시각·이력, 저장 API. 발송 작업이 설정을 참조하도록 연결. 카카오/푸시는 별도 발송 연동 필요 | 설정 준비 중 표시 |
| 이용권 구매·결제 수단·영수증 PDF | 결제 주문/승인 거래·결제 수단·영수증 정보, 결제 연동·구매 API. 기존 이용권에는 등록 금액/결제일만 있음 | 구매·영수증 버튼 비활성화, 결제 수단은 등록 정보 없음 |
| 회원 환불 신청 | 기존 관리자 즉시 환불 처리와 별도로 신청 상태·사유·처리자·결과를 관리할 신청 구조/API. 승인 시 기존 환불 서비스와 결제 취소 연결 | 예상액 조회와 센터 문의 안내 |
| 대시보드 지표 편집·운동 목표 | 회원별 표시 지표/주간 목표 설정 필드 또는 테이블과 조회·저장 API | 고정된 실제 통계 3개 표시, 가상 목표 문구 제거 |
| 비밀번호 변경 | 현재 비밀번호 확인/새 비밀번호 검증·해시 갱신·세션 처리 API. 기존 Member 테이블 활용 가능 | 준비 중 표시 |
| 카카오 연결 해제 | 본인 재인증·대체 로그인 수단 확보·외부 연결 해제 API. 기존 provider 필드 활용 여부 결정 | 실제 로그인 방식만 표시 |
| 회원 탈퇴 | 잔여 이용권/예약 정리, 보존/파기 정책, 본인 확인 API. 기존 회원 상태 필드 활용 가능 | 로그아웃을 탈퇴 완료로 안내하던 동작 제거 |
| 취소된 예약 이력 | 현재 취소 시 예약 행을 삭제하므로 취소 상태/시각을 보존할 필드 또는 이력 테이블·조회 API 필요 | 남아 있는 예약/출석/대기만 표시. 달력 범례에서 가상 취소 표시 제거 |
| 센터 운영시간·편의시설·수업 룸 | 센터 운영시간/시설 필드 및 관리 API, 수업별 룸 저장 구조 | 목업 운영시간·시설·룸 표시 제거 |
| 일시정지 승인·만료일 자동 연장 | 기존 홀딩은 기간 기록만 저장함. 승인 프로세스, 만료일 연장 및 예약 제한 정책이 필요하면 별도 서비스/API와 상태 구조 추가 | 기존 기간 기록 등록만 제공, 자동 연장 없음 명시 |
| 이용약관·개인정보·고객센터 링크 | 실제 문서/페이지 및 문의 채널 지정 | 이번 데이터 연동 범위에서 제외 |

## 확인 방법

백엔드를 재시작한 뒤 일반 회원으로 `/mypage`에 접속한다. 센터 변경 시 모든 위젯이 같은 센터를 보여야 하며, 데이터가 없는 계정은 0건/빈 상태를 보여야 한다. 취소·연락처·일시정지는 저장 후 재조회/새로고침에도 반영되어야 한다. 과거 출석 미기록 수업은 임의로 출석 완료 처리하지 않는다.

출석률은 출석 기록 수 / (출석 기록 수 + 결석 기록 수)다. 차감 이력은 기존 서버 계산과 동일하게 이용권의 센터·기간 내 예약/출석 수업을 중복 제거하며, 특정 이용권 ID에 직접 귀속되는 별도 원장은 아직 없다.
