## 1. 개요

### 한 줄 정의
부엉이 연구소 — 센터 운영·예약·이용권 관리

### 제품 목표
운영자는 센터/강사/수업/이용권/회원/예약을 한 곳에서 관리하고, 회원은 센터 선택부터 수업 예약·취소·대기까지 쉽게 처리할 수 있게 한다.

### 배경
현재 자료(메뉴 구조도/IA/기능정의서)를 보면, 센터(지점) 단위로 강사·수업·이용권·회원·예약 정책을 운영하는 서비스가 필요하다. 로그인/회원가입(회원·관리자)과 예약 플로우(수업 선택→정책 동의→최종 예약), 운영자 관리 화면(센터/강사/수업/이용권/회원 관리)이 함께 존재한다.

---

## 2. 문제 및 해결 방안

### 사용자 문제
센터 운영자는 센터/강사/수업/이용권/회원 정보를 여러 곳에서 관리해야 하고, 예약·대기·취소 정책(대기 자동/수동, 취소 가능 시간, 오픈 일정 등)을 일관되게 적용하기 어렵다. 회원은 예약 과정에서 수업 정보·잔여 이용권·취소 규정·결석 정책 등을 한 번에 확인하고 예약을 완료하기가 번거롭다. 또한 이메일 기반 가입/로그인만 제공될 경우 가입 단계에서 이탈이 발생하기 쉽다.

### 해결 방안
- **운영자(관리자)용:** 센터 관리(추가/편집/삭제), 강사 관리(추가/편집/삭제), 수업 관리(추가/편집/삭제), 예약 정책 관리(대기 확정 자동/수동, 대기 인원, 취소 가능 시간, 오픈 일정, 스케줄 생성), 이용권 관리(횟수/기간/중지/가격), 센터 회원 관리(회원 정보/이용권 부여·변경·삭제)를 제공한다.
- **회원용:** 로그인(이메일 또는 SNS 간편 로그인) 후 센터 선택→날짜 선택→수업 선택→수업 정보/정책 확인 및 동의→최종 예약, 그리고 예약 취소/대기, 마이페이지(예약/출석/결석 집계, 이용권 내역) 흐름을 제공한다.

### 차별점
예약 전 단계에서 '취소 가능 시간/결석 처리 정책/사용할 이용권 정보'를 한 화면에서 확인하고 동의 기반으로 예약을 확정하는 구조로 운영 리스크를 줄인다. 또한 센터 단위로 스케줄 생성(오픈 가능한 수업 생성)과 예약된 회원 관리까지 연결해, 운영자가 현장 운영에 필요한 정보를 빠르게 조회·조치할 수 있게 한다. 회원 가입/로그인 단계에서는 SNS 간편 로그인을 지원해 가입 전환율을 높인다.

## 3. 타겟 및 시나리오

### 타겟 사용자
1. **센터 운영자/관리자:** 피트니스/필라테스/스튜디오 등 센터를 운영하며 강사·수업·이용권·회원·예약을 관리해야 하는 담당자.
2. **센터 회원(일반 사용자):** 센터에서 수업을 예약하고 출석/결석 내역과 이용권 잔여 정보를 확인해야 하는 회원.

### 사용자 시나리오

**[운영자]**
관리자 로그인(이메일 기반) → 센터 리스트에서 센터 선택/편집 또는 센터 추가 → 강사/수업/이용권/센터 회원 정보 등록·수정 → 예약 정책(대기 자동/수동, 대기 인원, 취소 가능 시간, 오픈 일정, 스케줄 생성 기준) 설정 → 수업 스케줄 생성 후 예약된 회원 관리 → *(신규)* 노쇼/매출/알림 자동화 설정 → *(신규)* 강사 정산 확인.

**[회원]**
회원 로그인(이메일 또는 *(신규)* 카카오/네이버 SNS 로그인) → 예약할 센터 선택 → 날짜/수업 선택 → 수업 정보(강사, 정원, 대기, 시간) 및 취소 규정/결석 정책 확인 → 사용할 이용권 정보 확인 및 동의 → 최종 예약 → 필요 시 수업 취소 또는 대기 신청 → *(신규)* 대기 승격 알림 수신 → 마이페이지에서 예약/출석/결석 집계와 이용권 내역 확인.

## 4. 성공·위험 요소

### 핵심 지표
- **운영자:** 센터/강사/수업/이용권/회원 등록·수정 완료율, 스케줄 생성 성공률, 예약된 회원 관리 처리 시간, *(신규)* 노쇼율, *(신규)* 이용권 재등록 전환율
- **회원:** 예약 완료 전환율(센터 선택→최종 예약), 예약 취소/대기 신청 성공률, 마이페이지 방문 대비 내역 확인 완료율, *(신규)* 대기→확정 전환율, *(신규)* SNS 로그인 가입 전환율(이메일 대비)
- **공통:** 로그인 성공률/실패율, 이메일/휴대폰 인증 성공률

### 리스크
- 예약 정책(취소 가능 시간, 결석 처리, 대기 자동/수동) 정의가 불명확하면 분쟁/운영 혼선 발생
- 이용권(횟수/기간/홀딩) 규칙이 복잡해지면 예외 케이스 증가
- 관리자/회원 권한 분리 미흡 시 개인정보/운영 정보 노출 위험
- 이메일/휴대폰 인증 등 외부 인증 실패 시 가입/로그인 전환 하락
- *(신규)* 카카오 알림톡/SMS 발송 실패 시 회원 신뢰도 하락
- *(신규)* 노쇼 페널티 정책이 불명확하면 회원 불만/분쟁 소지
- *(신규)* SNS 계정과 기존 이메일 계정이 동일인일 경우 계정 통합/중복 가입 처리 정책 미비 시 데이터 정합성 문제 발생

## 10. 정책 참고 — SNS 로그인 범위

- **회원(필수 권장):** 카카오 로그인 우선 도입, 네이버 로그인 추가 검토. 구글/애플은 선택.
- **관리자(선택):** 사업자 정보(사업자등록번호 등)가 결부되어 있어 이메일 기반 정식 가입 유지를 기본으로 하고, SNS 로그인은 필요 시 추가 검토.
- **계정 통합 정책:** 동일 전화번호/이메일로 이미 가입된 사용자가 SNS로 재로그인 시도할 경우 자동 계정 연동 또는 안내 후 선택하게 하는 정책을 사전에 확정해야 함.
